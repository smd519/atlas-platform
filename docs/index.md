# Atlas Platform

Atlas is a modular Python data platform for ingesting, transforming, storing, and validating data using a
Medallion architecture (Bronze → Silver → Gold).

- [Platform Roadmap](roadmap.md): delivery matrix of modules against phases
- [High Level Platform Roadmap](HDROADMAP.md): delivery matrix of modules against phases
- [Architecture](architecture/platform-structure.md): structure, dependency rules, governance
- [Architecture Decisions](decisions/README.md): ADRs and the [template](decisions/0000-template.md)
- **Platform Modules**: per-module documentation, mirrored from each `modules/*/README.md`
- [Developer Onboarding](onboarding/README.md): setup and running your first pipeline

Module pages are generated from the module READMEs at build time, so those READMEs remain the single source of truth.
